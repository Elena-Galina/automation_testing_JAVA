### <p>1. <a href="https://github.com/Elena-Galina/JenkinsQA_Java_2025_fall">Training project:</a> UI test automation for the Jenkins application (RedRover School -  Enterprise style process, team collaboration).</p>
  <p><b> Tech stack: Java 17, Maven, Selenium, TestNG, RestAssured, IntelliJ IDEA, Git, GitHub, CI/CD (GitHub Actions), Chrome DevTools.</b></p>
<p>Developed automated tests in Java 17 (Selenium + TestNG) for job management scenarios.</p>
<p>Built stable XPath selectors by verifying their uniqueness in Chrome DevTools Console, analyzing DOM structure in the Elements tab, and validating request/response patterns in the Network tab.</p>
<p>Used RestAssured to prepare test data via the Jenkins API (creating jobs), then verified their display and behavior in the UI.</p>
<p>Integrated tests into a CI/CD pipeline (GitHub Actions): automatic execution on each push, code review required for every PR.</p>
<p>After run reports and logs were generated to assess results and localize failures.</p>
<p>Automation code and pipeline configurations are available in a <a href="https://github.com/Elena-Galina/JenkinsQA_Java_2025_fall">GitHub repository.</p>
