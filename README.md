### <p>1. <a href="https://github.com/Elena-Galina/JenkinsQA_Java_2025_fall">Educational project</a> for UI test automation of Jenkins.</p>

The project implemented with an Enterprise style workflow: team development, code review for every PR, CI/CD via GitHub Actions.

  <p><b> Tech stack: Java 17, Maven, Selenium, TestNG, RestAssured, IntelliJ IDEA, Git, GitHub, CI/CD (GitHub Actions), Chrome DevTools.</b></p>
<li><p> Developed automated tests in Java 17 (Selenium + TestNG) for job management scenarios.</p></li>
<li><p>Built stable XPath selectors by verifying their uniqueness in Chrome DevTools Console, analyzing DOM structure in the Elements tab, and validating request/response patterns in the Network tab.</p></li>
<li><p>Used RestAssured to prepare test data via the Jenkins API (creating jobs), then verified their display and behavior in the UI.</p></li>
<li><p>Integrated tests into a CI/CD pipeline (GitHub Actions): automatic execution on each push, code review required for every PR.</p></li>
<li><p>Post run reports and logs generated to quickly localize failures.</p></li>
<p><b>Automation code and pipeline configurations are available in the <a href="https://github.com/Elena-Galina/JenkinsQA_Java_2025_fall">GitHub repository.</b></p>
